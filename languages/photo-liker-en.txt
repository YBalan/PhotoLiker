# PhotoLiker language file: English (the texts of the program; this is also what is shown for any text a language file does not have).
#
# How a language file works
#   * The file is named  photo-liker-<code>.txt  (photo-liker-en.txt, photo-liker-ua.txt, photo-liker-de.txt ...), is UTF-8, and lies in the
#     "Languages" folder next to the program, or in  %LocalAppData%\PhotoLiker\Languages  (a file there wins over the one beside the program,
#     and survives a new version being installed). Every language found there is in the list of the Language row of the settings grid.
#   * The easiest way to add a language: copy this file to photo-liker-<code>.txt, change the three lines under "The language" and
#     translate the text after each "=". Keep the part before the "=" (the name of the text) as it is. A text that is left out, or whose
#     {0} {1} ... are not the same as in English, is shown in English.
#   * One text per line:  Name = text.  Empty lines and lines that begin with # are ignored.
#   * In a text:  \n is a new line,  \t a tab,  \\ a backslash,  \s a space (the spaces at the very start and end of a text are cut off,
#     so write \s where one is meant there).  {0} {1} ... are filled in by the program: keep them, in any order.
#   * A text of the form  one|many  (English) holds the forms of a noun for a number: "photo|photos".  A language with three forms
#     (Ukrainian: 1, 2-4, 5+) writes three: "фото|фото|фото".  See "Plural" below.
#   * The names of the rows of the grids (LikedFolder, Date Taken (Original) ...), of folders (Liked, Deleted) and what is typed into a search are
#     not texts of this file.
#
# The language
#   Name     the language in itself, as the Language row lists it
#   Culture  the .NET culture of the language (month names, the language of messages of the system): en, uk-UA, de-DE ...
#   Plural   how nouns follow a number: one-other (1 | the rest: English, German ...) or east-slavic (1, 21 | 2-4, 22-24 | the rest: Ukrainian, Russian ...)
Name = English
Culture = en
Plural = one-other
